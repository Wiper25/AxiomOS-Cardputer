# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | Yes |

## Reporting a vulnerability

Open a **private** security advisory on GitHub if available, or email the maintainer via GitHub profile.

Please do **not** file public issues for exploitable remote RCE / credential leaks until a fix is ready.

This firmware runs on a personal handheld device; treat Wi‑Fi credentials and MQTT passwords as sensitive.
